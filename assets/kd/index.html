三分钟上手

第一次用只有三步：贴牌谱 → 等 Mortal 算完 → 逐手看解读。 Python 和 Node 已经随包带好；提交牌谱要用 Chrome 或 Edge （full 版用包里自带的 Chromium），界面渲染用 WebView2 （Windows 11 自带，Windows 10 装过 Edge 一般也有；full 版用包里自带的固定版）。

  1. 贴牌谱，点「分析」 雀魂 / 天凤贴完整链接（game.maj-soul.com/1/?paipu=…、 tenhou.net/0/?log=…）；一番街、姬麻将贴对局 ID， 末尾的 @N 就是座位号。格式、模型、座次三个下拉不选也行。
  2. 等 1~5 分钟 程序会开一个浏览器窗口等你勾「我是人类」（可能要按提示选图），通过后把牌谱交给 Mortal； 拿回报告地址时窗口自动关闭，再本地生成解读。排队久时会慢一些，失败会写明卡在哪一步。
  3. 看解读 左边是牌桌，中间是 Mortal 的候选权重表（★ 是它的选择），右边是逐手解读。 用 [ ] 或底部按钮翻页，Home / End 切上下局， N 跳到下一处恶手。
卡住了？九成是网络或浏览器。分析时会自动弹出浏览器窗口，验证码就在里面勾， 勾完自动继续、窗口也会自己关掉；如果窗口没出来，再点一次「分析」， 或到设置里点「打开验证页面」先确认浏览器和网络是通的。 完整排查见程序目录下 docs/5_常见问题.md。

提交用的浏览器

提交牌谱要过一道人机验证（官网现在用 hCaptcha）。程序会自动开一个独立的 浏览器窗口、摆到前台并把验证框滚到中间，你在里面勾一下「我是人类」（可能要按提示选图）， 通过后自动继续——这是唯一稳定的方式，机器识别既不靠谱也违反对方条款。

窗口不用自己管：Mortal 一给出报告地址就自动关闭，不会停到解读跑完。

Chrome、Edge 都会自动找；Brave / Vivaldi / 360 极速等 Chromium 内核浏览器也能用，点「选择…」指到它的 exe 即可（Firefox 不行）。

「打开验证页面」会用一个独立窗口打开 Mortal 首页，可以先确认 浏览器与网络是通的；这里打开的窗口不会被自动关掉，用完自己关即可。

恶手门槛与档位 · 权重差

权重差 = 权重表里 Mortal 首选那张与你实战那张的百分比之差 （它 75%、你 25%，就是 50pt）。
门槛以上全部算恶手：都出解读、都给巡目上色、都计入「· 恶手 N 处」、都能跳过去； 门槛之下不进库，页面也翻不到。

填百分比。门槛之上只分两档，都算恶手，只是颜色不同： ≥ 严重 染红，门槛到严重之间染橙；默认 10 / 50。权重差 90% 以上会饱和 （Q 差 0.3 与 0.9 都可能是 99 对 1），所以它只分轻重，不衡量亏多少。

改门槛只对之后重算的牌谱生效：保存后跑一次「一键重建解读.bat」补缺 （或 rebuild.bat 全量重算）。

损失程度 · 期望损失 Q

Q 差 = Q(最优) − Q(实战)，直接反映这一手真正亏掉多少 （模型自己的尺度，不是点数）。它没有上限，所以能分出「权重差都是 100%」的两手谁更贵。
只影响解读面板右上角的「损失 严重 / 中等 / 轻微」，不改巡目颜色，也不影响「恶手 N 处」。

一手完全可能是「权重差 100pt · 损失 轻微」：Mortal 极度确信该打那张， 但两张牌其实差不多，换一下几乎不亏。
