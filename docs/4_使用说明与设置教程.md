# 使用说明与设置教程

这篇写给第一次打开 mortal-coach 的人。读完大约五分钟，之后你只需要「贴链接 → 等 → 看」。

---

## 一、先确认三件事

不需要装 Python、不需要装 Node、不需要装 Mortal —— 发行包里都带好了。默认发的是 **lite 版**
（用系统已有的浏览器与 WebView2）；另有可选的 full 版，仅附 WebView2 界面运行时；提交浏览器仍由用户安装。

| 条件 | 说明 |
|---|---|
| Windows 10 / 11 **64 位** | 目前只出 Windows x64 包；32 位 / ARM64 / macOS / Linux 都不能直接跑这个 EXE。 |
| 一个 Chromium 内核浏览器 | **lite 版（默认）**：Chrome 或 Edge 会自动找（只装了 Edge 也行），Brave / Vivaldi / 360 极速 / QQ 浏览器也能用，在设置里手动指到它的 exe（**Firefox 不行**，调试协议不同）。一个都没有时，分析请求会直接说明原因和下一步，不会崩溃或一直等待。full 版同样需要系统浏览器。 |
| 系统 WebView2 | 界面渲染用。**lite 版**：Windows 11 自带，Windows 10 一般随 Edge 更新装好；缺了界面起不来，启动时会弹框说明并给出官方下载地址（约 2 MB，不用重启电脑，装完重开应用）。**full 版自带固定版运行时，这一条也不用管**；只有 Windows 10 还需要给包内目录补两个 AppContainer 读执行权限（程序首次启动自动补，补不上会改用系统 WebView2 并说明）。full 版请解压到本地磁盘，不要放在网络盘或 UNC 路径。 |
| 能访问 `mjai.ekyu.moe` | 牌谱是交给线上 Mortal 算的。打不开这个站就一定分析不了。**只有分析新牌谱需要联网**；看已有报告、重新生成解释全程离线。 |

双击 `mortal-coach.exe` 就是全部安装过程。第一次启动会弹「三分钟上手」，关掉后可在 **⚙ 设置 → 使用说明 / 常见问题** 再打开。

---

## 二、五分钟上手

> **第一次**打开会自动弹一次「三分钟上手」。底部默认勾着 **不再自动提示**，关掉就不会再弹；
> 想重看就去 设置 →「使用说明 / 常见问题」，或者直接看这一章。取消勾选则下次启动还会提醒一次。
> 这个状态存在配置文件里，换机器、清浏览器缓存都不会丢。

### 第 1 步：贴牌谱

主页左边是「分析新牌谱」，把牌谱贴进去点 **分析**。

| 来源 | 该贴什么 | 样子 |
|---|---|---|
| 雀魂 | 整条牌谱链接 | `https://game.maj-soul.com/1/?paipu=261118-xxxx_xxxx` |
| 天凤 | 整条牌谱链接 | `https://tenhou.net/0/?log=20261118gm-xxxx` |
| 麻雀一番街 | **对局 ID，不是链接** | `ch35u1e9nc70954ah9n0@3` |
| 姬麻将 | 对局 ID | 对局页地址里 `log=` 后面那一段 |
| Mortal 报告页 | 报告页地址 | `https://mjai.ekyu.moe/report/...` |

- 一番街 ID 末尾的 `@N` 就是座位号（`@0` 东起、`@1` 南起、`@2` 西起、`@3` 北起）。没写 `@N` 时，在「复盘座次」里选，否则程序不知道要解读哪一家。
- 雀魂链接里带 `_a` 参数时座次能自动识别，下拉留「自动识别」即可。

### 第 2 步：三个下拉，不选也能跑

| 下拉 | 默认 | 什么时候要动 |
|---|---|---|
| 牌谱格式 | 自动识别 | 贴的是 Mortal 报告页、或 ID 被误判时才手动选。 |
| Mortal 模型 | `4.1b · 均衡` | 想复现别人用 4.1c / 4.0 算出的结论时才改。**不同模型的 rating / Q 值不能互相比较。** |
| 复盘座次 | 自动识别 | 一番街 / 姬麻将 ID 里没有 `@N`，或要按另一家的视角复盘时。 |

### 第 3 步：等 1~5 分钟

点「分析」之后，程序在后台依次做四件事：

1. 开一个**独立的、屏幕外的**浏览器窗口（用本副本实例目录下的 `chrome-profile`，跟你日常的浏览器互不干扰）；
2. 让它过 Cloudflare 人机验证（Turnstile），把牌谱提交给 Mortal；
3. 等 Mortal 算完，把报告 json 取回来；
4. 本地算牌理、写逐手解读、画对照图，存进牌谱库。

期间窗口会显示「正在提交 / 等待 Mortal / 生成解读」，不要关窗口。跑完自动跳到分析页。失败会明确写出**卡在哪一步**（阶段名），把它连同 `library/logs/<标签>.log` 一起看就能定位——对照 [常见问题](5_常见问题.md) 里的阶段码表。

### 第 4 步：读分析页

```
┌──────────────┬──────────┬─────────────────────┐
│              │ 局 / 巡  │  这一手的解读        │
│   牌桌回放    │ 跳转     │  ① ② ③ ④ 分页        │
│              │ Mortal   │  牌图 + 文字          │
│              │ 权重表   │                      │
└──────────────┴──────────┴─────────────────────┘
```

- **左**：killerducky 牌桌回放，Mortal 选的牌红框、你打的牌蓝框。
- **中**：局 / 巡两个下拉（带「· 恶手 N 处」），下面是 **Mortal 的候选权重表**：★ 是它的选择，`·你` 是你实战打的，条形长度是绝对权重（softmax 后），最后一列是 Q 值。表格跟着当前这一手走，不随解读翻页变化。
- **右**：逐手解读，一页一个思考点。

**恶手按权重差染色**：**巡目下拉**里，权重差 ≥ 严重线的标 **红**，其余（门槛之上）标 **橙**；
局数下拉只写「· 恶手 N 处」不上色。门槛之上**全部算恶手**——都出解读、都计数、都能用
「上一 / 下一恶手」跳，颜色只表示差得远不远。门槛与严重线都在
设置 →「恶手门槛与档位 · 权重差」里改（见第三节 3.1）。

解读面板右上角的徽章只写**损失程度**（`损失 严重 / 中等 / 轻微`），按期望损失 Q 单独算
（见第三节 3.2）；恶手类型、权重差、Q 值在鼠标悬停时显示。

解读页的固定顺序：

| 页 | 内容 |
|---|---|
| ① 局面 | 这一手在哪、什么场况、手牌与做牌方向。 |
| ② 攻防 | **只在有人立直 / 副露时出现**：威胁（谁在攻、几级）、本钱（向听 / 进张 / 成型点数）、退路（还剩几张强安牌），最后一句话结论：该攻、该守、还是不用取舍。 |
| ③ 关键点 | 每个 ①②③ 各占一页，写「为什么」和对应牌理（含《牌效率》《铳率原理》的口径）。 |
| ④ 结论 | 一句话该打哪张，以及「下次遇到同类局面怎么判断」。 |

**牌效类页面里，下面这些全部是牌面图，不是文字**：

- **正文里的牌**：写到「打 X」时 X 直接是一张牌图。
- **两手牌**：13 张切完的手牌（按面子 / 搭子 / 浮牌分组）。
- **有效牌**：全部铺开，每种牌下面标剩余枚数，右上角「几种 / 几枚」，不省略。
- **改良牌**：单独一张卡，左右对照两种切法各自的改良牌与枚数。

**第一行是「决定性要素」**：带金色左边条、★ 和淡金底色，一句话说清这一手在比什么
（牌效 / 打点 / 安全 / 向听）；它下面的论据行缩进、字号小一档。

**打点会被明确交代**：宝牌、断幺、役牌各有一套说法；其他役种（混一色、七对子、一气、
三色、一杯口）走通用番数对比——把两种切法的成型番数与点数各算一遍，差几番直接写。
番数相同也会写一句「两种切法成型番数相同，这一手的差别不在打点」，不会让你猜。

快捷键：

| 键 | 作用 |
|---|---|
| `[` / `]` | 上一页 / 下一页解读 |
| `Home` / `End` | 上一局 / 下一局 |
| `N` | 跳到下一处恶手 |
| `←` / `→` | 牌桌回放上一巡 / 下一巡 |

## 三、设置详解

主页右上角 **⚙ 设置**。

### 1. 牌谱库目录

所有产出都在这里：`report/`（Mortal 原始报告）、`coach/`（逐手解读）、`img_layout/`（对照图）、`logs/`（每次提交的完整日志）、`bad_moves.json`（恶手库）；提交浏览器的 profile 不放这里，见下。

| 操作 | 说明 |
|---|---|
| 选择… | 指到任意可写目录。想同步到网盘 / 移动硬盘就指过去。 |
| 打开 | 在资源管理器里打开当前库。 |
| 恢复默认 | 填回 `<程序目录>/library`，点「保存」生效。 |

切库时会**先尝试独占新库**：如果那个库正被另一个窗口写着，会直接拒绝并保持原样
（配置文件也不改），不会出现「切过去以后连删除都能删到别人库里」。想确认切换成功，
看右边的统计数字有没有跟着变。

- 右边会显示统计：`几局 · 几份报告 · 几张图 · 多少 MB`，可以据此判断库是不是指对了。
- **换机器**：把整个 `library` 拷过去，两边指向同一个路径（或重新选一次），历史牌谱、解读全在。
- 程序目录只读（例如装在 `Program Files`）时，配置会自动落到 `%LOCALAPPDATA%\mortal-coach\instances\<本副本标识>\config.json`（按程序目录各算一份，不同副本互不干扰），库默认也改到这个实例目录下，功能不受影响。

### 2. 提交用的浏览器

| 项 | 说明 |
|---|---|
| 勾「分析时显示浏览器」 | 勾选时显示窗口；未勾选时先后台等待自动验证，约 15 秒仍未完成只在应用内提示，可主动点「显示验证窗口」。人工确认后继续分析，不自动解验证码。 |
| 浏览器路径 | 留空 = 自动找 Chrome / Edge（也查注册表和常见安装路径）。要指定别的 Chromium 浏览器就点「选择…」。**别指到你日常在用的实例**——程序需要独立 profile 起一个新实例。 |

### 3. 恶手门槛与两套刻度

设置里分三段，各自独立：**「收不收」看门槛，「红还是橙」看权重差，「肉不肉疼」看 Q 损失**。

#### 3.1 门槛 · 权重差

权重差 = 权重表里 Mortal 首选那张与你实战那张的百分比之差（它 75%、你 25% 就是 50pt）。

| 项 | 说明 |
|---|---|
| 门槛 ≥ | 默认 **10%**。低于门槛的手**根本不进库**，页面上也翻不到 |
| 严重 ≥ | 默认 **50%**。门槛之上只分两档：≥50% 染红（严重），门槛到 50% 之间染橙（中等） |

- **门槛之上全部解析**：都出解读、都给巡目上色、都计入「· 恶手 N 处」、都能用「上一 / 下一恶手」跳；
  没有「入库了但不算」这种情况了。
- 门槛填得越低收得越多：10% 大约等于「Mortal 有六成把握而你选了别人」，再往下就是噪声
  （绝大多数决策点的权重差不到 5pt，收进来只会让「恶手 N 处」失真）。
- 门槛只影响**之后重算**的牌谱。改完保存，跑一次程序目录里的「一键重建解读.bat」（只补缺）
  或 `rebuild.bat`（全量），已有牌谱才会按新门槛重提。
- **局数下拉不上色**，只写「· 恶手 N 处」——一局里大多数巡都可能是恶手，整局染红没有信息量；
- 权重差在 90% 以上会饱和（Q 差 0.3 与 0.9 都可能是 99 对 1），所以它只用来分轻重，不衡量亏多少。

#### 3.2 损失程度 · 期望损失 Q

Q 差 = Q(最优) − Q(实战)，衡量这一手**真正亏掉多少**（模型自己的尺度，不是点数）。
它没有上限，所以能分出「权重差都是 100%」的两手谁更贵。

| 项 | 说明 |
|---|---|
| 严重 ≥ | 默认 **0.70** |
| 中等 ≥ | 默认 **0.30** |

只影响解读面板右上角的「损失 严重 / 中等 / 轻微」，**不改巡目颜色、不计入恶手数**。

> 一手完全可能是「权重差 100pt · 损失 轻微」：Mortal 极度确信该打那张，但两张牌其实差不多。
> 反过来也有「权重差 35pt · 损失 严重」——它自己都只有六成把握，但换错代价很大。

改完点「保存」→ 回主页重开一局生效（门槛改动需重跑流水线）。
配置写在 `mortal-coach.json` 的 `bad`（`thresh` / `gap` / `loss` 三段），
旧版 `metric/severe/medium` 或上一版三档写法都会自动迁移，不用手改。

### 4. 高级：运行时

只有在想把包内的 Python / Node 换成系统安装版时才改。**填了就用你填的**（优先级高于包内 `runtime/`），
填的路径不存在时才回落到包内。

## 四、日常维护

| 场景 | 做法 |
|---|---|
| 某局解读缺失 / 报错 | 双击 `一键重建解读.bat`：只补缺的、失败的、版本过期的局。 |
| 解读规则升级后想全部刷新 | 双击 `rebuild.bat`（全量，约 16~33 秒 / 局，14 局约 9 分钟）。 |
| 想换 Mortal 模型重算 | 重新提交同一牌谱即可，会生成带字母后缀的新标签（同一天多局）。 |
| 空间不够 | 只删 `img_layout/` 里的图不影响解读文字；实例目录里的 `chrome-profile` 删掉后下一局需要重新过一次验证。 |
| 备份 | 拷 `library/`；`report/` 是最值钱的部分（重算解读不用重新提交 Mortal）。 |

## 五、隐私

- 牌谱会发到 `mjai.ekyu.moe`（社区 Mortal 服务），和你用网页版提交是同一件事。
- 除牌谱本身，不上传任何东西；解读、图片、权重全部在本地算。
- 浏览器 profile 只用于过验证，不读你日常浏览器的数据。

遇到报错先看 [常见问题](5_常见问题.md)，那里按「失败的阶段码」逐条给了原因和处理办法。
